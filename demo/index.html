Add "Ask AI about this page" in one tag

A tiny button row that opens ChatGPT, Claude, Perplexity, Gemini, Grok, Mistral or DeepSeek with a prefilled prompt. No backend, no tracking, no dependencies.

  • 11.06 kB gzip (CDN build)
  • 8.14 kB gzip with the lite entry + 2 logos
  • 0 runtime dependencies
  • 7 services
  • HTML, React, Vue, Svelte

    The ask-ai:open event
    
    
    Every open dispatches a bubbling ask-ai:open event from the widget root with { service, prompt, url } in detail. Click any button on this page and watch the log. Use it for analytics.

  const { service, prompt, url } = e.detail;
  plausible("Ask AI", { props: { service } });
});
