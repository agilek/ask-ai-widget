# html

Plain HTML using the CDN build (`dist/ask-ai.min.js`, global `AskAI`): a predefined prompt, user-question mode (`input`), and the zero-JS `data-ask-ai` auto-mount with `--aai-*` CSS overrides.

Run `npm run build` at the repo root, then open `index.html` in a browser (no install needed). In your own page, load the script from a CDN such as `https://cdn.jsdelivr.net/npm/ask-ai-widget/dist/ask-ai.min.js`.
